## 👨‍💻 About me

I'm an IT Systems Administration student who learns by building. I run my own **Proxmox homelab**, self-host my website at [fr3e.ca](https://fr3e.ca), and write shell scripts to automate the boring parts of setting up and maintaining Linux systems.

- 🎓 Studying **IT Systems Administration** ([my course notes](https://github.com/fr3e1/NAIT-ITSA-notes))
- 🖥️ Daily-driving **Arch Linux** with a custom Hyprland setup
- 🧪 Running a homelab with **Proxmox VE**, VMs, and LXC containers for hands-on practice
- 🌱 Currently leveling up in **Bash scripting, networking, Active Directory, and web deployment**
- 💼 **Open to** co-op placements, internships, and junior IT / help desk / sysadmin roles
